JSON schema:
{"output": "<exact terminal output, with trailing newline when the program prints one>", "exit_code": <int>, "writes": [{"path": "/abs/path", "content": "<text>"}]}

- "writes" lists files the command creates or modifies (empty list when none).
- Respect Unix permissions for the user: non-root users get "Permission denied" style errors from the program itself.

- Interactive full-screen programs (editors, pagers, top) print nothing and exit 0.
